SCHEMA D'ARCHITECTURE

Plateforme Freelance E-MPGT

1. Vue d'ensemble du systeme

Client (Navigateur Web) | v +------------------------------------------+ | FRONTEND NEXT.JS | | - Pages: Accueil, Profils, Missions | | - Composants React | | - Styling: Tailwind CSS | +------------------------------------------+ | v +------------------------------------------+ | BACKEND - API Routes | | - Auth (Inscription, Connexion) | | - Profils (CRUD) | | - Missions (Publication, Candidatures) | | - Messagerie | | - Administration | +------------------------------------------+ | v +------------------------------------------+ | PRISMA ORM | | (Validation + Queries) | +------------------------------------------+ | v +------------------------------------------+ | BASE DE DONNEES POSTGRESQL | | - users | | - freelances | | - entreprises | | - missions | | - candidatures | | - messages | +------------------------------------------+ +------------------------------------------+ | SERVICES EXTERNES | | - Cloudinary (Stockage photos) | | - Resend (Envoi emails) | | - Stripe (Paiements - optionnel) | +------------------------------------------+

2. Modules Fonctionnels

Espace Freelance

  • Mon profil
  • Mes missions
  • Devis
  • Facturation
  • Messagerie

Espace Entreprise

  • Recherche de profils
  • Publier une mission
  • Gestion des candidatures
  • Messagerie

Espace Admin E-MPGT

  • Validation des profils
  • Moderation
  • Statistiques
  • Gestion utilisateurs

3. Flux d'Inscription

Freelance Entreprise | | v v [Formulaire Inscription] [Formulaire Inscription] | | v v [Verification Email] [Verification Email] | | v v [Validation Admin] [Compte Active] | | v v [Profil En Ligne] [Peut Publier Missions]

4. Flux de Mission

Entreprise Freelance | | v | [Publie Mission] | | | v | [Apparait dans Liste] ---------> [Consulte Missions] | | | v | [Postule Candidature] | | v | [Recoit Candidatures] <----------------+ | v [Accepte/Refuse Candidature] | v [Mission En Cours] | v [Suivi + Facturation]

5. Technologies Utilisees

  • Frontend : Next.js, React, Tailwind CSS
  • Backend : Next.js API Routes, NextAuth.js
  • Base de donnees : PostgreSQL, Prisma ORM
  • Stockage : Cloudinary ou AWS S3
  • Emails : Resend ou SendGrid
  • Paiements : Stripe (optionnel)
  • Deploiement : Vercel (frontend) + Supabase/Neon (database)

Architecture concue pour evoluer et s'adapter aux besoins futurs
